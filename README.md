# TMCF Church Reconstruction Fund Tracker ⛪

An interactive, mobile-first web application for **The Methodist Church Foundation (TMCF)** to track amounts collected for church reconstruction.

## 🌟 Key Features

- **Public Ledger**: Anyone with the link can view records, see reconstruction progress metrics, and search/filter entries without logging in.
- **Excel Export (`.xlsx`)**: One-click download button generating formatted `.xlsx` spreadsheets for local offline record-keeping and official reports.
- **Pastor Admin Portal**:
  - Credentials:
    - **Name**: `Pallapati Cornelius`
    - **Password**: `Pallapati Cornelius`
  - Restricts adding new records, editing existing records, and deleting records exclusively to Pastor Cornelius.
  - Allows Pastor to adjust the overall Reconstruction Target Goal directly from the UI.
- **Record Details Supported**:
  - Donor Name
  - Address / Location
  - Amount (in ₹ INR)
  - Date & Time
  - Optional Payment Proof / Receipt Screenshot Image
  - Payment Notes / Reference
- **Mobile Responsive**: Designed for touchscreens on smartphones and desktop screens alike.

## 🚀 How to Run Locally

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev
```

Open `http://localhost:5173/` in your mobile or desktop browser.
